This folder goes on GitHub Pages (or any free static host), NOT on Neocities.
Setup steps: see OFFSITE in D:\Important\neocities\cards\README.txt.

bridge.html  relays the site's requests to the guestbook and the instrument APIs,
             because free Neocities pages may not contact other websites themselves.
             If you add a new API to the site, add its host to ALLOWED_HOSTS in here.
*.mp3        the mp3s, because free Neocities accounts refuse .mp3 uploads.
